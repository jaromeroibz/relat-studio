# D — RELAT Website Product Brief

## 1. Website Objective

The RELAT website should function as:

1. The primary brand experience.
2. The studio portfolio.
3. A sales tool.
4. A demonstration of design and development capability.
5. A qualification mechanism for potential clients.

The website itself must be the strongest proof of what RELAT can do.

---

## 2. Primary Conversion

**Start a conversation with RELAT.**

Secondary:

- view selected work
- understand services
- learn about the studio
- contact RELAT
- request a project discussion

Avoid making the website feel like a traditional lead-generation funnel.

---

## 3. Core Principle

### Show, don't explain.

The interaction, typography, motion, imagery and composition should demonstrate creativity.

Keep copy concise.

Use visual storytelling wherever possible.

---

## 4. Suggested Structure

### HOME

Hero  
Selected Work  
Capabilities  
Approach  
Additional Work  
About  
CTA

### WORK

Portfolio and project pages.

### SERVICES

Concise explanation of capabilities.

### ABOUT

Founder, philosophy and approach.

### CONTACT

Simple conversation-oriented form.

---

## 5. Hero

The hero should communicate:

**RELAT is different.**

Possible conceptual directions:

### Direction A

**WE BUILD DIGITAL EXPERIENCES.**

### Direction B

**DIGITAL, WITH PURPOSE.**

### Direction C

**RELAT**

with a concise descriptor.

Do not select the final headline purely from text. Test it visually.

---

## 6. Navigation

Keep navigation minimal.

Suggested:

**RELAT**

Work  
Services  
About  
Contact

The navbar should be integrated into the composition.

Reference:

- J T Hospitality
- Instrument
- Locomotive

---

## 7. Project Presentation

Projects should be interactive.

On hover:

- image changes
- additional imagery appears
- project information becomes visible
- image scales
- typography shifts
- background may change

Primary reference:

**Studio Freight**

Projects should feel editorial and exploratory.

---

## 8. Case Studies

Use:

**Challenge → Approach → Result**

Keep copy short.

Let visual work occupy most of the page.

---

## 9. Scroll Experience

Scrolling should feel like moving through a sequence.

Potential behaviors:

- background transitions
- typography scaling
- image masks
- horizontal movement
- pinned sections
- subtle parallax
- card elevation
- image zoom
- project transitions

References:

**Instrument** for color/background transitions.

**Nagi** for cinematic scroll behavior.

**Locomotive** for typography and artistic interaction.

**VM Concepts** for movement and whitespace.

---

## 10. Loader

The loader can be a short brand moment.

Possible concepts:

- RELAT wordmark
- light
- movement
- connection
- sequence

Keep it short and performant.

Reference:

**Cure**

---

## 11. Background Transitions

The site should be able to move between:

**light → dark → warm → light**

through smooth section transitions.

These changes should create rhythm rather than feel decorative.

---

## 12. Cards

Cards should not look like standard SaaS cards.

Prefer:

- image-first layouts
- fluid shapes when appropriate
- subtle elevation
- hover scaling
- image zoom
- depth
- movement

---

## 13. Responsive Design

Design deliberately for:

- desktop
- tablet
- mobile

Do not simply shrink the desktop design.

Mobile should be its own composition.

Reduce motion where necessary for usability and performance.

---

## 14. Performance

Priorities:

- fast initial load
- optimized images
- lazy loading
- efficient animation
- minimal unnecessary JavaScript
- accessibility
- responsive behavior
- semantic HTML
- SEO fundamentals

Visual effects must never compromise performance.

---

## 15. Technical Direction

Preferred stack:

- React
- Vite
- Tailwind CSS
- modern animation libraries where appropriate
- semantic HTML
- optimized image delivery

Do not introduce dependencies without a clear purpose.

---

## 16. SEO

Potential targets:

- web design Costa Rica
- web development Costa Rica
- digital studio Costa Rica
- website design Santa Teresa
- web design Santa Teresa
- creative web design Costa Rica
- digital experiences Costa Rica

SEO should support the brand without making the copy unnatural.

---

## 17. Conversion

Avoid aggressive CTAs.

Prefer:

> Start a conversation.

> Let's build something.

> Tell us about your project.

> Have something in mind?

The CTA should feel human.

---

## 18. Final Website Feeling

When visitors finish exploring, they should think:

> "These people understand design."

Then:

> "They understand technology."

And finally:

> "I want them to build this for me."

The website should not simply explain RELAT.

**The website should make the visitor experience RELAT.**
